# Dragon Animation 🐉

A simple yet captivating interactive dragon animation built with HTML, CSS, and JavaScript.

## Description 

This project features a dragon that follows your mouse cursor across the screen. The dragon is constructed using SVG elements for the head, fins, and spine, and animated using JavaScript to create a fluid, organic movement.

## Features 

- **Interactive Movement**: The dragon follows the mouse pointer.
- **Responsive Design**: Adapts to window resizing.
- **SVG Graphics**: Scalable vector graphics for the dragon's body parts.

## How to Run 

1. Clone or download the repository.
2. Open `index.html` in your web browser.
3. Move your mouse to see the dragon follow you!

## Technologies Used 

- **HTML5**: Structure and SVG definitions.
- **CSS3**: Styling and layout.
- **JavaScript**: Animation logic and interaction.

## Project Structure ​​​​​​​​​​​

- `index.html`: Main file containing the HTML structure and SVG definitions.
- `script.js`: Contains the logic for the dragon's movement and animation.
- `style.css`: Contains the styles for the background and layout.
